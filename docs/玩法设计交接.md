## 1. 你现在要做什么

为一个**少儿英语学习平台**设计「关卡内的游戏玩法」。

- 受众：小学 3 年级到初二，7–14 岁
- 设备：**电脑浏览器为主，手机也要能用**（手机端后做，但不能设计成只能鼠标操作）
- 每个知识点 = 一颗星球 = 一种题型，**每关 15 题**；一颗星球有多关（关数 = 该星球套数，2–95）
- 玩家每次玩一关大约 3–5 分钟

**你的产出**：一份可交付给开发的设计文档，能回答“每一帧画面上有什么、玩家怎么操作、按下之后发生什么”。

**你不负责**：写代码、改代码、设计数据库、设计奖励数值（这些已定，见第 3 节）。

## 3. 已经定死的规则（不要改，也不要重新讨论）

### 三层奖励

```
答对 1 题 = 1 朵小红花
3 朵小红花 = 1 颗星星
5 颗星星  = 1 个徽记（该星球专属）
```

- 全程**手动兑换**，不自动变
- 一套 15 题全对 = 15 花 = 5 星 = 1 个徽记
- 答错的题不给花，要在错题本**连对 3 次**补发，每题只补一次
- **一套的错题全部补完，才凑得满 15 朵、拿到徽记**

### 七颗星球

| 星球 | 等级 | 题型 | 徽记 | 套数 | 产奖励 |
|---|---|---|---|---|---|
| 字母表 | L1 | letter | — | 1 | ❌ 纯练 |
| 基础问候词 | L1 | word | 🥚 破壳蛋 | 22 | ✅ |
| 常用单词 | L2 | word | 🐻 小熊 | 32 | ✅ |
| 简单拼写 | L2 | spelling | ✍️ 羽毛笔 | 27 | ✅ |
| 单词跟读 | L2 | pronunciation | 🐦 唱歌小鸟 | 29 | ✅ |
| 听力理解 | L3 | listening | — | 1 | ❌ 纯练 |
| 拼写进阶 | L3 | spelling | 🔮 水晶球 | 95 | ✅ |

**纯练星球**（字母表、听力理解）：不产花/星/徽记，界面上不显示任何计数，只有「已完成 / 未完成」。完成 = 15 题全对。

### 解锁条件

- **L2**：字母表完成 + 基础问候词 3 个 🥚
- **L3**：常用单词 3 🐻 + 简单拼写 2 ✍️ + 单词跟读 2 🐦
- 达标后点「能力测试」星门 → 10 题对 8 过 → 解锁下一级
- 等级可回访，进度保留

### 关卡基础设定

| 项 | 已定 |
|---|---|
| 一关 | 15 题，随机序 |
| 命（心） | 3 条，**纯视觉**，不扣任何数值 |
| 命扣完 | 不结束、不影响奖励 |
| 计时 | 记录用时，**不限时** |
| 跳过 | 允许，不记作答 |
| 中途退出 | 进度保留，回来还是同一题 |
| 重听（听力） | 共 2 次机会（自动播 1 次 + 可重听 1 次） |
| 重练 | 允许，花/星/徽记都不变 |

## 5. 四个玩法（现在只有名字，等你设计细节）

### 5.1 拖卡喂星球 — 字母题 / 单词题（占题库 825 题）

已有一句话描述：
> 题干在上；中央一颗呼吸的星球；下方 4 张卡。桌面拖拽入星球，手机点卡片飞入。答对星球吞卡，答错卡片弹回。

**你要补的**：这颗星球长什么样？吞卡是什么动画？卡片飞行的轨迹和时长？答错时星球怎么“摇头”？

### 5.2 字母砖拼词 — 拼写题（占题库 1830 题）

已有一句话描述：
> 释义在上；一行拼写槽；下方字母砖。点砖落入槽；槽满出现「✓ 就这样」由孩子确认。

**你要补的**：字母砖多大？多少块？打乱后什么顺序？点错能不能撤回？「✓ 就这样」出现在哪？

### 5.3 听音找词 — 听力题（15 题）

已有一句话描述：
> 一个大唱片按钮 + 4 张卡。进题自动播 1 次，可重听 1 次。

**你要补的**：唱片按钮怎么转？播放时有什么视觉反馈？重听按钮显示什么状态？用完了怎么提示？

### 5.4 麦克风跟读 — 跟读题（435 题）

已有一句话描述：
> 单词大字 + 麦克风按钮 + 实时音量条。按住说话，松开识别。

**你要补的**：音量条长什么样？识别中 / 识别成功 / 失败分别什么状态？相似度 1–3 星怎么显示？**麦克风不可用时怎么降级**（设计成“听一遍 + 我读过了”）？

## 7. 设计时必须回答的问题

每写一个玩法，请把这 7 条写清楚，否则开发会自由发挥：

1. **静态画面**：这一帧屏幕上有什么元素，各自在哪、多大
2. **操作方式**：拖 / 点 / 输入 / 说；桌面和手机分别怎么做
3. **完整交互流程**：从「玩家开始操作」到「进入下一题」，中间几步、每步发生什么
4. **成功反馈**：视觉（什么动、动多久）+ 音效
5. **失败反馈**：视觉 + 音效 + 是否停住
6. **边界**：长单词、词组、字母砖不够用、麦克风没权限
7. **无障碍**：只用键盘能不能玩；关掉动画会怎样

## 9. 已知约束（别设计成做不到的）

| 约束 | 说明 |
|---|---|
| **不能引入新依赖** | 只用 Vue 3 + Element Plus + 浏览器原生能力（CSS 动画、Web Audio、SVG） |
| **不能用外部素材** | 不下载图片/音频；图标用 emoji 或 SVG 自绘，音效用 Web Audio 合成 |
| **手机端后做** | 但设计要写清手机怎么做（触摸、点选代替拖拽） |
| **跟读依赖 Google 服务** | 本机不可用，必须设计降级路径 |
| **题库不能再造** | 题干、选项、答案都是现成数据，设计只能在“怎么呈现”上做文章 |
