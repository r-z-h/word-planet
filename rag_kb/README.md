# 帮助知识库（RAG 语料）

这是给"站内 AI 问答助手"使用的**独立知识库**，面向**用户（孩子/家长）**，不是开发说明书。

## 目录
- `articles/*.md`：一篇篇面向用户的帮助文章（按主题分）。RAG 会把它们切成片段、做向量索引，检索后用 LLM 综合成回答。

## 原则
1. **独立**：本目录与 `需求说明书.md`、`Agent实现说明书.md`、`AGENTS.md` 等**开发文档解耦**。这里只放用户该看的内容，不含表结构、接口、部署等实现细节。
2. **用户口吻**：面向孩子/家长，用简单中文解释"是什么、为什么、怎么做"。
3. **数字口径**：这里的数值（如 3 花=1 星、能力测试对 8 题、提醒 19:00）用于**解释**；涉及"我当前还差多少"这种实时数值，由后端规则层从数据库查，不依赖本知识库。
4. **可维护**：内容由产品/内容维护，改完重新构建索引即可；代码不用动。

## 维护方式
- 新增/修改主题：直接编辑或新增 `articles/*.md`，一篇一个主题、按标题和段落组织（便于切块）。
- 改完重建索引（后续由 `backend/rag_engine` 的构建脚本完成）。
- 数值若与产品代码不一致，以规则层（数据库/常量）为准，并同步更新本文。
